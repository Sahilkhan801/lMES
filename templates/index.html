System Overview

The **Legal Metrology Enforcement System (LMES)** is designed to support the **Department of Consumer Affairs (DoCA)** in automating enforcement checks under the **Legal Metrology (Packaged Commodities) Rules, 2011**.

In retail stores, hypermarkets, and e-commerce platforms, millions of packaged items are distributed daily. Checking their labels manually for metrological declarations (e.g. MRP format, Net Qty units, Consumer Cell info, and packing dates) is extremely resource-intensive. LMES implements computer vision, optical character recognition (OCR), and an active rules checking system to flags packaging defects in seconds.

Legal Background: Rule 6 of Legal Metrology (Packaged Commodities) Rules, 2011 outlines mandatory declarations. Rule 7 specifies structural details like text heights and placements. Non-compliance is punishable by fines or product confiscation.

LMES Architecture & Technical Pipeline

The system is built as a lightweight python microservice integrated with a modern Single Page Web Dashboard:

Frontend SPA HTML5 / Vanilla CSS / JS
Flask Backend Router app.py
OCR Extract Engine ocr_service.py
Rule Evaluation compliance_checker.py

Key Components:

  • Frontend App: Interfaces drag-and-drop file uploads, displays real-time laser scanner animations, handles OCR inline adjustments, and renders analytical charts using Chart.js.
  • OCR Extraction (ocr_service.py): Leverages Tesseract OCR with OpenCV preprocessing (CLAHE, denoising, adaptive thresholding) and a multi-pass extraction strategy (PSM 3, PSM 11, binarized fallback) to maximize text detection accuracy and produce real bounding box coordinates.
  • Compliance Checker (compliance_checker.py): The core analysis engine. Parses text using highly specific regular expressions and checks declarations against conditions stored in rules.json.
  • Lightweight Database (scans_db.json): Flat-file JSON DB storing logs of scans, audit ratings, and violations for traceability.
  • PDF Generator (pdf_generator.py): Generates executive audit compliance certificates containing signature fields, raw OCR transcripts, and compliance checklists in PDF format.

OCR Engine & Error Handling

The system uses real Tesseract OCR with OpenCV image preprocessing. There are no mock, simulated, or filename-matched fallbacks — every scan runs genuine optical character recognition on the uploaded image.

Multi-Pass OCR Pipeline (ocr_service.py)
def extract_text(image_path):
    # 1. Auto-detect Tesseract engine path
    tess_path = find_tesseract_path()
    if not tess_path:
        return "[ERROR] Tesseract OCR engine not found."

    # 2. Preprocess with OpenCV (CLAHE, denoise, threshold)
    denoised, thresh, scale, w, h = preprocess_image(image_path)

    # 3. Multi-pass extraction for maximum accuracy:
    #    Pass 1: PSM 3 on denoised image
    #    Pass 2: PSM 11 (sparse) for missed declarations
    #    Pass 3: PSM 3 on adaptive threshold for remaining
    boxes = run_tesseract_pass(pil_denoised, scale, 3, patterns)
    # ... fallback passes for missing keys ...

    # 4. On failure: honest error messages only
    #    "[NO TEXT DETECTED]" or "[ERROR] ..." — never fake data

Error Handling Philosophy

  • Tesseract not installed: Returns [ERROR] Tesseract OCR engine not found. Please install Tesseract or set the TESSERACT_CMD environment variable.
  • Image unreadable: Returns [ERROR] Could not load or read image file.
  • No text found: Returns [NO TEXT DETECTED] Could not read text from this label

No fabricated text is ever returned under any circumstance.

To account for low-resolution pictures or OCR mistakes, the interface integrates an Interactive OCR Correction Editor. Officials can edit the OCR stream directly inside the dashboard and click "Re-check" to re-calculate rules on the updated text.

Metrology Rules, 2011 Standards

Rule Item Standard Format Requirement Non-Compliance Examples
Maximum Retail Price "MRP Rs 150.00 (incl. of all taxes)" or "MRP Rs 150.00 (inclusive of all taxes)" "Price: Rs 150", "MRP: Rs 150" (without inclusive of taxes text)
Net Quantity Numeric value followed by standard units (g, kg, ml, l, pcs, N) "Net Weight: 500 gms" (non-standard unit), "Qty: 1 box"
Month/Year of Pack MM/YYYY, MM-YYYY or Month Name Year (e.g. 08/2026) "Date: 2026" (missing month), "08/26" (non-compliant 2-digit year)
Consumer Care Must include contact Name, Address, Helpline phone, and Email ID "Helpline: 1800-xx" (missing email), "For complaints, contact manufacturer" (missing phone/email)

Deployment Guide

Follow these steps to deploy LMES to local servers or hosting platforms:

System Dependencies

# Install Python 3.10+ (Tested on Python 3.14)
# Install Tesseract OCR Engine (REQUIRED for real OCR):
# Windows: C:\Program Files\Tesseract-OCR\tesseract.exe
# Ubuntu: sudo apt install tesseract-ocr

Python Environment Setup

# Create virtual environment
python -m venv venv

# Activate Virtual Environment
# Windows PowerShell:
.\venv\Scripts\Activate.ps1
# Linux/macOS:
source venv/bin/activate

# Install requirements
pip install Flask Pillow pytesseract reportlab

Run Application Server

# Start development Flask server
python app.py
# The portal will launch at: http://127.0.0.1:5000/
